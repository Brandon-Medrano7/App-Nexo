# Simplificación de pantallas · 14 de octubre de 2026

Objetivo: mostrar primero la información necesaria para decidir y ofrecer explicaciones bajo demanda.

- Inicio: presupuesto libre como cifra principal, próxima paga, próximo pago y tres movimientos recientes. Resumen mensual desplegable y acceso breve a Guía y herramientas.
- Presupuesto: Ver cálculo despliega límite, gastos, reserva, referencia diaria y fechas. Edición accesible; historial y actualización manual en Más opciones.
- Pagos: resumen del siguiente vencimiento; Administrar pagos despliega lista, edición, vinculación, cancelación y nuevo pago.
- Nuevo movimiento: títulos cortos, importe y detalles; dictado opcional en Registrar por voz.
- Metas: progreso y Aportar a la vista; referencia semanal, retiro, historial y edición dentro de Detalles y opciones.
- Perfil: menos texto repetido; reglas, logros y accesorios bajo demanda.
- Guía: conversor dentro de Herramientas, sin competir con las respuestas.

Los avisos de error y confirmaciones de operaciones se conservan. No se modificaron cálculos, contratos del servidor ni datos guardados. La lista completa de movimientos sigue accesible desde Ver todo.

Validación: compilación Android y pruebas unitarias existentes aprobadas. La revisión visual de pantallas autenticadas, texto grande y TalkBack debe completarse con sesión abierta; no se afirma una mejora medida de usabilidad hasta probar con personas.
